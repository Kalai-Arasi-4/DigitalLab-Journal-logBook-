Experiment 2: CSS3 Styling

AIM:

To design a webpage using CSS3 styles including inline, internal, external styles, background and text properties.

REQUIREMENTS:

  • HTML5 and CSS3 supported browser
  • Text Editor (e.g., VS Code)

PROCEDURE:

  1. Create a new HTML file and include HTML5 structure.
  2. Apply Inline CSS within an element.
  3. Use Internal CSS inside the <style> tag.
  4. Link an External CSS file (optional).
  5. Use background and text properties for design.
  6. Save and open in browser to see the result.
