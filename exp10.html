Experiment No. 10

CONVERT A XML PAGE INTO HTML PAGE USING XSLT – DigitalLab Journal / Logbook

AIM:

To convert an XML document into an HTML web page using XSLT, in order to display structured data in a well-formatted and user-friendly manner for the DigitalLab Journal / Logbook application.

ALGORITHM:

Step 1: Start
Step 2: Create the XML document with required data.
Step 3: Create the XSLT stylesheet for transforming XML into HTML.
Step 4: Link the XSLT file in the XML using xml-stylesheet processing instruction.
Step 5: In XSLT, define <xsl:template match="/"> to start HTML structure.
Step 6: Use <xsl:value-of> and <xsl:for-each> to extract XML data.
Step 7: Save both XML and XSL files.
Step 8: Open the XML file in a web browser to view the transformed HTML.
Step 9: Display and verify output.
Step 10: Stop.

SCRIPT:

exp10.xml
<?xml version="1.0" encoding="UTF-8"?>
<?xml-stylesheet type="text/xsl" href="exp10.xsl"?>
<logbook>
  <entry>
    <student>Kalaiyarasi A</student>
    <rollno>23CS101</rollno>
    <experiment>XML to HTML using XSLT</experiment>
    <guide>Dr. Manikandan S</guide>
    <date>2025-11-03</date>
  </entry>
</logbook>

exp10.xsl
<?xml version="1.0" encoding="UTF-8"?>
<xsl:stylesheet xmlns:xsl="http://www.w3.org/1999/XSL/Transform" version="1.0">
<xsl:template match="/">
  <html>
    <head><title>Logbook Report</title></head>
    <body style="font-family:Arial; background:#f4f9ff;">
      <h2 style="color:#004a91;">DigitalLab Journal Entry</h2>
      <table border="1" cellpadding="8" style="border-collapse:collapse;">
        <tr bgcolor="#004a91" style="color:white;">
          <th>Student</th>
          <th>Roll No</th>
          <th>Experiment</th>
          <th>Guide</th>
          <th>Date</th>
        </tr>
        <xsl:for-each select="logbook/entry">
          <tr>
            <td><xsl:value-of select="student"/></td>
            <td><xsl:value-of select="rollno"/></td>
            <td><xsl:value-of select="experiment"/></td>
            <td><xsl:value-of select="guide"/></td>
            <td><xsl:value-of select="date"/></td>
          </tr>
        </xsl:for-each>
      </table>
    </body>
  </html>
</xsl:template>
</xsl:stylesheet>

OUTPUT:

The XML file when opened in a browser displays a formatted HTML table showing student details and experiment data using the applied XSLT transformation.
